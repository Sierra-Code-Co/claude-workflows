# references/

External or third-party content kept for reference: comparisons of other AI coding agents, terminal setup notes, orchestration patterns, etc.

## What's in here

| Subdirectory                                | Purpose                                                                                          |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| [`learn-coding-agents/`](./learn-coding-agents/) | Notes on alternative AI coding agents (opencode, codex-cli, kilo-code), terminal setup, AI orchestration patterns. Originally a standalone local-only repo (no GitHub remote, zero commits). Consolidated here 2026-04-27. |

## Why these are in this repo (not separate)

- They're **workflow knowledge**, same audience and purpose as the rest of `claude-workflows`
- Originals had no remote → at risk of single-machine loss
- One-stop shop for "how I work with AI coding agents" — even when the answer isn't "Claude Code"

## What this is NOT

Not for project-specific references (those live in each project's `docs/`). Not for user-facing docs. Reference content for ME, when I want to compare approaches or remember a pattern.
